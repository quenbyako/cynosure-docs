# Примеры использования Cynosure

:::tip[Готовые агенты]

Пока что готовых предзаготовленных агентов нет, их основная идея — по одной ссылке как claude code plugins установить их. Для каждого агента будет по отдельному репозиторию.

:::

На этой странице мы собрали самые интересные примеры использования Cynosure.

## Продуктивность и помощь в работе

### Менеджер проектов

Следит за дедлайнами, создает задачи из переписки и напоминает о встречах.

### Email-ассистент

Разбирает входящие, пишет черновики ответов и выделяет самое важное (нужен соответствующий MCP).

### Юрист

Анализирует длинные документы на предмет скрытых рисков и условий.

## Контент и маркетинг

### SEO-копирайтер

Ищет тренды, подбирает ключевые слова и пишет посты, которые залетают в поиск.

### SMM-стратег

Придумывает контент-план на неделю и адаптирует один текст под разные соцсети.

### Сценарист для Reels/YouTube

Пишет структуру видео, придумывает хуки и расписывает тайминги.
