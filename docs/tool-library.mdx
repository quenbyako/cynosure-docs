# Библиотека полезных инструментов

На этой странице мы собрали наш набор инструментов, которые мы используем сами. Это не все возможные инструменты, которые можно использовать с Cynosure, но возможно эта страница даст вам идеи, каких инструменты вы можете дать в руки своим агентам.


### Asana

`https://mcp.asana.com/mcp`

Позволяет управлять задачами в Asana.

### Wix Websites MCP Server

`https://mcp.wix.com/sse`

Позволяет управлять сайтами в Wix.

### Figma

`https://mcp.figma.com/mcp`

Позволяет управлять файлами в Figma.

### Box

`https://mcp.box.com`

Позволяет управлять файлами в Box.
