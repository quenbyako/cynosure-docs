# Агент Координатор

Основная задача Cynosure — это создание и поддержка "офиса для агентов", то есть дать пространство для ваших агентов организованно вам помогать.

Однако, пустой офис не очень-то и полезен, поэтому при запуске бота первый доступный вам агент — это Агент-Координатор. Он выполняет роль HR менеджера, ищет агентов, которые могут быть полезны для ваших задач, а так же помогает в их управлении.

Координатор — это единственный агент, который живет в основном чате. Его главная задача — понимать потребности и собирать "команду" из подходящих специалистов-агентов для их решения.

## Что умеет Координатор?

Координатор — это универсал. С ним можно просто поболтать, или попросить решить простую проблему. Но его истинная суперсила проявляется в менеджменте других агентов.

### Как «нанять» нового агента

Для того, чтобы получить нового агента, не нужно использовать никаких сложных интерфейсов или команд. Достаточно просто попросить Координатора в свободной форме.

*   *«Наими мне юриста, который поможет проверить договор аренды».*
*   *«Мне нужен агент-копирайтер для ведения моего Telegram-канала».*
*   *«Создай спеца, который будет следить за моими задачами в Notion».*

Как только ты это сделаешь, Координатор создаст отдельную ветку (**Топик**) в Telegram. Как только координатор подберет нужные навыки и сформирует для агента его обязанности, можно начинать работу с ним.

:::tip[Почему это удобно?]

Разделение на топики позволяет каждому агенту держать в памяти только то, что касается его работы. Юрист не будет отвлекаться на твои идеи для постов, а копирайтер не полезет в твои задачи в Notion.

При этом, если копирайтер напишет что-то про право, можно переключиться на агента-юриста, который сможет дать свою экспертную оценку, а затем снова вернуться к работе с копирайтером.

:::

## Управление командой

Координатор помнит всех, кого он нанял. Можно спросить у него: «Кто у нас сейчас в команде?» или попросить изменить настройки конкретного агента.
