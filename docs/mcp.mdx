# Управление MCP серверами


## Как добавить свой сервер

Cynosure поддерживает работу с любыми MCP серверами (HTTP, SSE), которые имеют ссылку на доступ к ним. Большинство серверов поддерживают анонимную OAuth авторизацию без регистрации отдельного приложения (череез dynamic client registration). Агент использует именно эту идею.

:::note

Некоторые MCP сервера работают с помощью локальных инструментов, такие сервера помечаются `stdio`, либо в инструкции к ним не имеют никаких ссылок (например в инструкции написано просто "установите `uvx blender-mcp`", и нет никакой ссылки). Например, некоторые сервера работают с **локальными** приложениями (Photoshop, Blender, и прочие).

Cynosure **не поддерживает** работу с такими серверами. Такие сервера требуют запуска на локальном компьютере, поэтому они не могут быть добавлены в бота.

:::

Как только агент получает запрос добавить сервер и ссылку, он сначала делает probing сервера: проверяет можно ли зарегестрироваться, можно ли авторизоваться, доступен ли сервер анонимно. Если он может самостоятельно зарегестрироваться — агент просто создает клиент, и отправляет в чат ссылку, что бы пользователь авторизовался.

После того, как агент разберется с вашим сервером, он отправит вам ссылку на авторизацию. Вам необходимо перейти по ссылке и авторизоваться в нужном сервисе. После этого агент сможет пользоваться инструментами сервера.

:::danger

Будьте внимательны, и используйте только ссылки на официальные MCP сервера!

:::

## Разница между инструментами, аккунтами и серверами,

**Сервер** — это адрес, куда подключается ваш агент. На одном сервере может быть сколько угодно аккаунтов. Например, если вы используете Todoist как на работе, так и дома, то вы можете использовать один и тот же сервер, но подключить два аккаунта. Сервера публичны, и доступны для всех пользователей

**Аккаунт** — это профиль, под которым вы авторизовались на сервере. У одного сервера можно авторизоваться под разными аккаунтами (например, если в Figma вам нужен рабочий и личный аккаунт, то вы можете добавить оба аккаунта одновременно). При этом у этих аккаунтов может быть разный набор инструментов. Каждый аккаунт — ваша собственность. Их никто не может использовать, кроме ваших агентов

**Инструмент** — это конкретная функция, которая доступна агенту, например "получить список встреч", или "нарисовать картинку". Инструменты могут автоматически добавляться и удалятья даже без действий вас, или агента: например, вы оплатили Pro подписку в каком-нибудь сервисе, с которой добавляется инструмент по анализу данных — этот инструмент автоматически будет добавлен в ваш список инструментов, и для этого не нужно ничего дополнительно делать.

MCP сервера могут иметь абсолютно разный набор инструментов, например в зависимости от подписки на сторонний сервис, которая есть у пользователя, или от корпоративного доступа. Инструменты даже могут добавляться или удаляться автоматически.

## Включение и выключение инструментов

Сервера, как и аккаунты просто дают доступ к определенному набору инструментов, и сами по себе не используются. Инструменты же — прямые "руки" агентов, с которыми они взаимодействуют с миром.

Для того, что бы у агента был определенный набор инструментов, он включается через списки доступа, allow list и block list. Каждый агент **всегда** работает только с фильтрами, поскольку набор инструментов может меняться автоматически даже без участия пользователя или агента.

## Ошибка в создании клиента

Иногда MCP сервера не поддерживают динамическую регистрацию, и агент может **не** справиться с добавлением сервера самостоятелыно. Если такое происходит, то необходимо написать в поддержку, что бы клиент зарегестрировали в сервисе самостоятельно. Никакой модерации у проекта не существует, добавлять можно любые сервера, однако из-за специфики работы OAuth авторизации, иногда требуется создать клиент через поддержку.
